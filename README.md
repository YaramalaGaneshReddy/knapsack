# 0/1 Knapsack

A C++ dynamic-programming solution for the 0/1 knapsack problem.

## Complexity

- Time: `O(n * capacity)`
- Space: `O(n * capacity)`

## Compile

```bash
g++ knapsack.cpp -o knapsack
```

## Run

```bash
./knapsack
```

Enter the item count, weights, profits, and knapsack capacity.

```text
3
10 20 30
60 100 120
50
Maximum value = 220
```
